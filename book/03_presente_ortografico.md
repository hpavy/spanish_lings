# 03. Presente de indicativo — cambios ortográficos

## Regla

Estos cambios no son "irregularidades" reales: son ajustes de ortografía
para mantener el mismo sonido de la raíz en todas las personas. El sonido
no cambia, solo la letra escrita.

| patrón | regla | ejemplo |
|---|---|---|
| **-cer / -cir** → zc | antes de o (yo) | conocer → cono**zc**o |
| **-guir** → g | se pierde la u antes de o/a | seguir → si**g**o |
| **-ger / -gir** → j | antes de o/a (para mantener sonido /x/) | coger → co**j**o |
| **-uir** → y | se inserta y en las personas "de bota" | construir → constru**y**o |

Los cambios car/gar/zar (buscar → busqu-, llegar → llegu-, empezar →
empec-) **no afectan al presente**; aparecen en el subjuntivo y en el
pretérito (yo). Se explican en los capítulos 06 y 13.

## Ejemplos

**conocer**

| persona | forma |
|---|---|
| yo | conozco |
| tú | conoces |
| él/ella/usted | conoce |
| nosotros | conocemos |
| vosotros | conocéis |
| ellos/ellas/ustedes | conocen |

**seguir** (también tiene cambio de raíz e→i, ver capítulo 02)

| persona | forma |
|---|---|
| yo | sigo |
| tú | sigues |
| él/ella/usted | sigue |
| nosotros | seguimos |
| vosotros | seguís |
| ellos/ellas/ustedes | siguen |

**coger**

| persona | forma |
|---|---|
| yo | cojo |
| tú | coges |
| él/ella/usted | coge |
| nosotros | cogemos |
| vosotros | cogéis |
| ellos/ellas/ustedes | cogen |

**construir**

| persona | forma |
|---|---|
| yo | construyo |
| tú | construyes |
| él/ella/usted | construye |
| nosotros | construimos |
| vosotros | construís |
| ellos/ellas/ustedes | construyen |

## Errores comunes

- Escribir *seguo* en vez de *sigo* (se pierde la u de "gu" antes de o).
- Escribir *construo* en vez de *construyo* (falta la y).
