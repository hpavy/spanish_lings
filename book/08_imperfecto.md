# 08. Imperfecto de indicativo

## Regla

El imperfecto describe acciones habituales, procesos en curso o
descripciones de fondo en el pasado — sin marcar principio ni fin claro
(a diferencia del pretérito, que es puntual y cerrado).

Es el tiempo **más regular** del español: solo tres verbos son
irregulares (ser, ir, ver), y ni siquiera de forma extrema.

| terminación | yo | tú | él/ella/usted | nosotros | vosotros | ellos/ellas/ustedes |
|---|---|---|---|---|---|---|
| -ar | -aba | -abas | -aba | -ábamos | -abais | -aban |
| -er / -ir | -ía | -ías | -ía | -íamos | -íais | -ían |

Nota: -er e -ir comparten exactamente las mismas terminaciones.

## Los tres irregulares

**ser**

| persona | forma |
|---|---|
| yo | era |
| tú | eras |
| él/ella/usted | era |
| nosotros | éramos |
| vosotros | erais |
| ellos/ellas/ustedes | eran |

**ir**

| persona | forma |
|---|---|
| yo | iba |
| tú | ibas |
| él/ella/usted | iba |
| nosotros | íbamos |
| vosotros | ibais |
| ellos/ellas/ustedes | iban |

**ver**

| persona | forma |
|---|---|
| yo | veía |
| tú | veías |
| él/ella/usted | veía |
| nosotros | veíamos |
| vosotros | veíais |
| ellos/ellas/ustedes | veían |

(*ver* no es realmente irregular — es la raíz regular *ve-* + las
terminaciones normales de -er; solo parece raro porque el verbo es corto.)

## Ejemplos regulares

**hablar**

| persona | forma |
|---|---|
| yo | hablaba |
| tú | hablabas |
| él/ella/usted | hablaba |
| nosotros | hablábamos |
| vosotros | hablabais |
| ellos/ellas/ustedes | hablaban |

**comer**

| persona | forma |
|---|---|
| yo | comía |
| tú | comías |
| él/ella/usted | comía |
| nosotros | comíamos |
| vosotros | comíais |
| ellos/ellas/ustedes | comían |

## Errores comunes

- Olvidar el acento en nosotros (*hablabamos* ✗ → *hablábamos* ✓,
  *comiamos* ✗ → *comíamos* ✓). Nosotros siempre lleva tilde en imperfecto.
- Confundir *era* (ser, imperfecto) con *fue* (ser, pretérito) — la
  elección entre los dos depende del matiz (descripción vs. hecho puntual),
  no es un error de conjugación sino de uso.
