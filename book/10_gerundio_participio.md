# 10. Gerundio y participio pasado

## Gerundio

Se forma con la raíz + **-ando** (-ar) o **-iendo** (-er/-ir). No varía
según la persona — es una forma única, como el infinitivo.

| terminación | gerundio |
|---|---|
| -ar | -ando |
| -er / -ir | -iendo |

**Casos especiales:**

- Verbos -ir con cambio de raíz débil (capítulo 06) aplican ese mismo
  cambio en el gerundio: dormir → **durmiendo**, pedir → **pidiendo**,
  decir → **diciendo**, seguir → **siguiendo**.
- Verbos -ir con diptongo aplica e -> i
- Verbos -uir insertan una y: construir → **construyendo**.
- ir es irregular: **yendo** (no *iendo*).

## Participio pasado

Se usa en los tiempos compuestos (capítulos 11-12, 15) y como adjetivo.
Regla general:

| terminación | participio |
|---|---|
| -ar | -ado |
| -er / -ir | -ido |

**Participios irregulares** (hay que memorizarlos, no siguen ninguna
regla):

| infinitivo | participio |
|---|---|
| hacer | hecho |
| decir | dicho |
| escribir | escrito |
| poner | puesto |
| ver | visto |
| ser | sido |
| ir | ido |
| romper | roto |
| resolver | resuelto |
| abrir | abierto |
| cubrir | cubierto |
| volver | vuelto |
| morir | muerto |

Nota: los compuestos de estos verbos heredan la misma irregularidad
(descubrir → descubierto, devolver → devuelto, componer → compuesto...).

## Ejemplos

Gerundio:

| infinitivo | gerundio |
|---|---|
| hablar | hablando |
| dormir | durmiendo |
| pedir | pidiendo |
| construir | construyendo |
| ir | yendo |
| decir | diciendo |

Participio:

| infinitivo | participio |
|---|---|
| hablar | hablado |
| vivir | vivido |
| hacer | hecho |
| escribir | escrito |
| romper | roto |
| resolver | resuelto |
| ver | visto |

## Errores comunes

- Escribir *dormiendo* con la raíz sin cambiar — el cambio débil o→u sí
  se aplica en gerundio (*durmiendo* ✓).
- Regularizar los participios irregulares (*hacido* ✗ → *hecho* ✓,
  *escribido* ✗ → *escrito* ✓). Son de los errores más frecuentes en
  hablantes no nativos porque el cerebro quiere aplicar la regla general.
