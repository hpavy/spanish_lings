# 06. Pretérito — cambios ortográficos y de raíz

## Cambios ortográficos (car / gar / zar)

Solo afectan a la persona **yo**, para mantener el sonido de la consonante
final de la raíz:

| terminación | cambio | ejemplo |
|---|---|---|
| -car | c → qu | buscar → bus**qu**é |
| -gar | g → gu | llegar → lle**gu**é |
| -zar | z → c | empezar → empe**c**é |

El resto de las personas es completamente regular.

## Cambio de raíz débil (verbos -ir)

Los verbos -ir con cambio de raíz en presente (capítulo 02) tienen **un
segundo cambio, más débil**, que aparece en el pretérito — pero solo en
**él/ella/usted** y **ellos/ellas/ustedes** (las terceras personas):

| cambio fuerte (presente) | cambio débil (pretérito) | ejemplo |
|---|---|---|
| e → ie | e → i | sentir → sintió, sintieron |
| e → i | e → i | pedir → pidió, pidieron |
| o → ue | o → u | dormir → durmió, durmieron |

Nosotros/vosotros y yo/tú son regulares en el pretérito de estos verbos.

## Ejemplos

**buscar**

| persona | forma |
|---|---|
| yo | busqué |
| tú | buscaste |
| él/ella/usted | buscó |
| nosotros | buscamos |
| vosotros | buscasteis |
| ellos/ellas/ustedes | buscaron |

**empezar**

| persona | forma |
|---|---|
| yo | empecé |
| tú | empezaste |
| él/ella/usted | empezó |
| nosotros | empezamos |
| vosotros | empezasteis |
| ellos/ellas/ustedes | empezaron |

**dormir**

| persona | forma |
|---|---|
| yo | dormí |
| tú | dormiste |
| él/ella/usted | durmió |
| nosotros | dormimos |
| vosotros | dormisteis |
| ellos/ellas/ustedes | durmieron |

**pedir**

| persona | forma |
|---|---|
| yo | pedí |
| tú | pediste |
| él/ella/usted | pidió |
| nosotros | pedimos |
| vosotros | pedisteis |
| ellos/ellas/ustedes | pidieron |

## Errores comunes

- Aplicar el cambio de raíz a nosotros (*durmimos* ✗ → *dormimos* ✓). Esta
  persona es regular tanto en presente como en pretérito — el cambio de
  raíz nunca toca a nosotros/vosotros en ningún tiempo.
- Escribir *empezé* en vez de *empecé* (la z siempre se convierte en c
  antes de e).
