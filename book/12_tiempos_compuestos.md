# 12. Pluscuamperfecto, futuro perfecto, condicional perfecto

## Regla

Los tres siguen la misma lógica que el pretérito perfecto (capítulo 11):
**haber conjugado en el tiempo correspondiente + participio invariable**.
Solo cambia el tiempo de *haber*.

| tiempo compuesto | haber en... | ejemplo (hablar) |
|---|---|---|
| pluscuamperfecto | imperfecto | había hablado |
| futuro perfecto | futuro | habré hablado |
| condicional perfecto | condicional | habría hablado |

## Ejemplos

**pluscuamperfecto** — acción pasada anterior a otra acción pasada
("cuando llegué, ya había salido")

| persona | forma |
|---|---|
| yo | había hablado |
| tú | habías hablado |
| él/ella/usted | había hablado |
| nosotros | habíamos hablado |
| vosotros | habíais hablado |
| ellos/ellas/ustedes | habían hablado |

**futuro perfecto** — acción que estará terminada en un punto futuro
("para las cinco, habré terminado")

| persona | forma |
|---|---|
| yo | habré hablado |
| tú | habrás hablado |
| él/ella/usted | habrá hablado |
| nosotros | habremos hablado |
| vosotros | habréis hablado |
| ellos/ellas/ustedes | habrán hablado |

**condicional perfecto** — hipótesis sobre el pasado ("habría ido, pero
no pude")

| persona | forma |
|---|---|
| yo | habría hablado |
| tú | habrías hablado |
| él/ella/usted | habría hablado |
| nosotros | habríamos hablado |
| vosotros | habríais hablado |
| ellos/ellas/ustedes | habrían hablado |

## Errores comunes

- Usar la raíz irregular de *haber* en futuro/condicional pero olvidar
  que sigue las mismas reglas del capítulo 09 (habr-, no haber-):
  *haberé* ✗ → *habré* ✓.
- Cambiar el participio (mismo error que en el capítulo 11): siempre
  invariable.
