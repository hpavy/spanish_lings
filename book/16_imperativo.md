# 16. Imperativo

## Regla clave: el afirmativo y el negativo no comparten formas

Esta es la trampa principal del imperativo: **el imperativo afirmativo
tiene su propio paradigma solo para tú/vosotros**, mientras que el
**negativo (y usted/ustedes/nosotros en ambos casos) usa el subjuntivo
presente** (capítulo 13).

| persona | afirmativo | negativo |
|---|---|---|
| tú | forma propia (o = él en presente indicativo, verbos regulares) | no + subjuntivo |
| usted | subjuntivo | no + subjuntivo |
| nosotros | subjuntivo (excepto ir → vamos) | no + subjuntivo |
| vosotros | infinitivo sin -r, + -d | no + subjuntivo |
| ustedes | subjuntivo | no + subjuntivo |

## Tú afirmativo

Para verbos regulares y con cambio de raíz, es idéntico a la forma de
**él/ella/usted en presente de indicativo**: habla, come, vive, duerme,
pide.

Ocho verbos tienen una forma **irregular corta**, hay que memorizarlos:

| infinitivo | tú afirmativo |
|---|---|
| decir | di |
| hacer | haz |
| ir | ve |
| poner | pon |
| salir | sal |
| ser | sé |
| tener | ten |
| venir | ven |

## Vosotros afirmativo

Siempre regular: se quita la -r del infinitivo y se añade -d.

hablar → hablad, comer → comed, vivir → vivid, tener → tened, decir →
decid. Único irregular real: **ir → id**.

## Nosotros afirmativo

Usa el subjuntivo presente ("hablemos", "comamos", "tengamos"), con una
excepción: **ir → vamos** (no *vayamos*, aunque *vayamos* también se
usa en registro más formal/negativo).

## Ejemplos

**hablar**

| persona | afirmativo | negativo |
|---|---|---|
| tú | habla | no hables |
| usted | hable | no hable |
| nosotros | hablemos | no hablemos |
| vosotros | hablad | no habléis |
| ustedes | hablen | no hablen |

**tener**

| persona | afirmativo | negativo |
|---|---|---|
| tú | ten | no tengas |
| usted | tenga | no tenga |
| nosotros | tengamos | no tengamos |
| vosotros | tened | no tengáis |
| ustedes | tengan | no tengan |

**decir**

| persona | forma |
|---|---|
| tú | di |
| usted | diga |
| nosotros | digamos |
| vosotros | decid |
| ustedes | digan |

**ir**

| persona | forma |
|---|---|
| tú | ve |
| usted | vaya |
| nosotros | vamos |
| vosotros | id |
| ustedes | vayan |

**ser**

| persona | forma |
|---|---|
| tú | sé |
| usted | sea |
| nosotros | seamos |
| vosotros | sed |
| ustedes | sean |

## Errores comunes

- Usar la forma afirmativa de tú en negativo (*no habla* ✗ → *no hables*
  ✓). El negativo siempre pasa por el subjuntivo, sin excepción.
- Confundir *sé* (imperativo de ser) con *se* (pronombre reflexivo) —
  llevan tilde diferenciadora.
- Vosotros negativo usa subjuntivo (*no habléis*), no la forma en -d
  (*no hablad* ✗).
