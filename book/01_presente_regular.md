# 01. Presente de indicativo — verbos regulares

## Regla

Los verbos regulares se dividen en tres grupos según la terminación del
infinitivo: **-ar**, **-er**, **-ir**. Se quita la terminación para obtener
la raíz, y se añade la terminación correspondiente a cada persona.

| terminación | yo | tú | él/ella/usted | nosotros | vosotros | ellos/ellas/ustedes |
|---|---|---|---|---|---|---|
| -ar | -o | -as | -a | -amos | -áis | -an |
| -er | -o | -es | -e | -emos | -éis | -en |
| -ir | -o | -es | -e | -imos | -ís | -en |

Nota: -er e -ir comparten casi todas las terminaciones; solo difieren en
**nosotros** (-emos / -imos) y **vosotros** (-éis / -ís).

## Ejemplos

**hablar**

| persona | forma |
|---|---|
| yo | hablo |
| tú | hablas |
| él/ella/usted | habla |
| nosotros | hablamos |
| vosotros | habláis |
| ellos/ellas/ustedes | hablan |

**comer**

| persona | forma |
|---|---|
| yo | como |
| tú | comes |
| él/ella/usted | come |
| nosotros | comemos |
| vosotros | coméis |
| ellos/ellas/ustedes | comen |

**vivir**

| persona | forma |
|---|---|
| yo | vivo |
| tú | vives |
| él/ella/usted | vive |
| nosotros | vivimos |
| vosotros | vivís |
| ellos/ellas/ustedes | viven |

## Errores comunes

- Confundir las terminaciones de **-er** e **-ir** en nosotros/vosotros
  (*vivemos* ✗ → *vivimos* ✓).
- Olvidar el acento en vosotros (*habláis*, *coméis*, *vivís* — todos llevan
  tilde).
