# 15. Subjuntivo compuesto

## Regla

Mismo principio que los tiempos compuestos de indicativo (capítulos 11-12):
**haber conjugado + participio invariable**. Aquí *haber* se conjuga en
subjuntivo (presente o imperfecto).

| tiempo | haber en... | ejemplo (hablar) |
|---|---|---|
| pretérito perfecto de subjuntivo | subjuntivo presente | haya hablado |
| pluscuamperfecto de subjuntivo | subjuntivo imperfecto -ra | hubiera hablado |
| pluscuamperfecto de subjuntivo | subjuntivo imperfecto -se | hubiese hablado |

*Haber* en subjuntivo presente es completamente irregular (haya, hayas,
haya, hayamos, hayáis, hayan) — no sigue el patrón "raíz de yo +
terminación" del capítulo 13, hay que memorizarlo aparte.

*Haber* en imperfecto de subjuntivo sí sigue la regla del capítulo 14
(pretérito de ellos "hubieron" → raíz "hubie-" + terminación).

## Ejemplos

**pretérito perfecto de subjuntivo**

| persona | forma |
|---|---|
| yo | haya hablado |
| tú | hayas hablado |
| él/ella/usted | haya hablado |
| nosotros | hayamos hablado |
| vosotros | hayáis hablado |
| ellos/ellas/ustedes | hayan hablado |

**pluscuamperfecto de subjuntivo (-ra)**

| persona | forma |
|---|---|
| yo | hubiera hablado |
| tú | hubieras hablado |
| él/ella/usted | hubiera hablado |
| nosotros | hubiéramos hablado |
| vosotros | hubierais hablado |
| ellos/ellas/ustedes | hubieran hablado |

**pluscuamperfecto de subjuntivo (-se)**

| persona | forma |
|---|---|
| yo | hubiese hablado |
| tú | hubieses hablado |
| él/ella/usted | hubiese hablado |
| nosotros | hubiésemos hablado |
| vosotros | hubieseis hablado |
| ellos/ellas/ustedes | hubiesen hablado |

## Errores comunes

- Confundir *haya* (subjuntivo) con *halla* (de *hallar*) o *haiga*
  (forma no estándar, evitar). La forma correcta siempre es *haya*.
- Este tiempo es clave para las oraciones condicionales con "si" en
  pasado: *si hubiera sabido, habría venido* — la combinación
  pluscuamperfecto de subjuntivo + condicional perfecto es típica de C1.
