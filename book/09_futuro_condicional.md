# 09. Futuro y condicional

## Regla

Futuro y condicional son los únicos dos tiempos que **usan el infinitivo
completo como raíz** (no se quita la terminación -ar/-er/-ir), y comparten
exactamente las mismas irregularidades de raíz.

| terminación futuro | yo | tú | él/ella/usted | nosotros | vosotros | ellos/ellas/ustedes |
|---|---|---|---|---|---|---|
| todos los verbos | -é | -ás | -á | -emos | -éis | -án |

| terminación condicional | yo | tú | él/ella/usted | nosotros | vosotros | ellos/ellas/ustedes |
|---|---|---|---|---|---|---|
| todos los verbos | -ía | -ías | -ía | -íamos | -íais | -ían |

Las mismas terminaciones sirven para -ar, -er e -ir — no hay tres grupos
aquí, solo uno.

## Verbos con raíz irregular

Los mismos 12 verbos son irregulares en ambos tiempos, porque la
irregularidad está en la raíz, no en la terminación:

| infinitivo | raíz irregular |
|---|---|
| tener | tendr- |
| poner | pondr- |
| salir | saldr- |
| valer | valdr- |
| venir | vendr- |
| poder | podr- |
| saber | sabr- |
| caber | cabr- |
| haber | habr- |
| querer | querr- |
| hacer | har- |
| decir | dir- |

Se pueden agrupar en tres patrones: se pierde la vocal antes de -r
(tener→tendr-, poner→pondr-...), o se contrae más (hacer→har-, decir→dir-).

## Ejemplos

**hablar** (futuro)

| persona | forma |
|---|---|
| yo | hablaré |
| tú | hablarás |
| él/ella/usted | hablará |
| nosotros | hablaremos |
| vosotros | hablaréis |
| ellos/ellas/ustedes | hablarán |

**tener** (futuro)

| persona | forma |
|---|---|
| yo | tendré |
| tú | tendrás |
| él/ella/usted | tendrá |
| nosotros | tendremos |
| vosotros | tendréis |
| ellos/ellas/ustedes | tendrán |

**decir** (condicional)

| persona | forma |
|---|---|
| yo | diría |
| tú | dirías |
| él/ella/usted | diría |
| nosotros | diríamos |
| vosotros | diríais |
| ellos/ellas/ustedes | dirían |

## Errores comunes

- Aplicar el cambio de raíz del presente al futuro (*tiendré* ✗ →
  *tendré* ✓) — el futuro usa el infinitivo completo, no la raíz del
  presente, así que los cambios de raíz e→ie/o→ue del capítulo 02 **no
  existen en futuro/condicional**.
- Olvidar el acento en todas las personas del futuro excepto nosotros
  (*hablare* ✗ → *hablaré* ✓).
