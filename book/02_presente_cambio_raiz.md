# 02. Presente de indicativo — verbos con cambio de raíz

## Regla

Los verbos "de bota" (*boot verbs*) cambian la vocal de la raíz cuando esa
vocal recae en la sílaba tónica. Esto ocurre en **todas las personas excepto
nosotros y vosotros**, porque en esas dos personas el acento cae en la
terminación, no en la raíz — por eso el dibujo del patrón parece una bota.

Cuatro cambios posibles:

| cambio | ejemplo | infinitivo → raíz cambiada |
|---|---|---|
| e → ie | querer | quer- → quier- |
| o → ue | poder | pod- → pued- |
| e → i | pedir | ped- → pid- |
| u → ue | jugar | jug- → jueg- |

## Ejemplos

**querer** (e → ie)

| persona | forma |
|---|---|
| yo | quiero |
| tú | quieres |
| él/ella/usted | quiere |
| nosotros | queremos |
| vosotros | queréis |
| ellos/ellas/ustedes | quieren |

**pedir** (e → i)

| persona | forma |
|---|---|
| yo | pido |
| tú | pides |
| él/ella/usted | pide |
| nosotros | pedimos |
| vosotros | pedís |
| ellos/ellas/ustedes | piden |

**dormir** (o → ue)

| persona | forma |
|---|---|
| yo | duermo |
| tú | duermes |
| él/ella/usted | duerme |
| nosotros | dormimos |
| vosotros | dormís |
| ellos/ellas/ustedes | duermen |

**jugar** (u → ue)

| persona | forma |
|---|---|
| yo | juego |
| tú | juegas |
| él/ella/usted | juega |
| nosotros | jugamos |
| vosotros | jugáis |
| ellos/ellas/ustedes | juegan |

## Errores comunes

- Aplicar el cambio en nosotros/vosotros (*quiéremos* ✗ → *queremos* ✓).
- Los verbos -ir con cambio e→i o o→ue tienen **un segundo cambio débil**
  que afecta al pretérito, gerundio y subjuntivo — se explica en el
  capítulo 06.
