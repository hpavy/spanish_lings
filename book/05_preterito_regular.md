# 05. Pretérito — verbos regulares

## Regla

El pretérito indefinido expresa una acción terminada en el pasado, vista
como un punto cerrado (a diferencia del imperfecto, que describe procesos
o hábitos — ver capítulo 08).

| terminación | yo | tú | él/ella/usted | nosotros | vosotros | ellos/ellas/ustedes |
|---|---|---|---|---|---|---|
| -ar | -é | -aste | -ó | -amos | -asteis | -aron |
| -er | -í | -iste | -ió | -imos | -isteis | -ieron |
| -ir | -í | -iste | -ió | -imos | -isteis | -ieron |

Nota: -er e -ir comparten exactamente las mismas terminaciones en pretérito
(a diferencia del presente).

También nota: **nosotros** de los verbos -ar es idéntico en presente y
pretérito (*hablamos* puede ser "hablamos ahora" o "hablamos ayer") — el
contexto desambigua.

## Ejemplos

**hablar**

| persona | forma |
|---|---|
| yo | hablé |
| tú | hablaste |
| él/ella/usted | habló |
| nosotros | hablamos |
| vosotros | hablasteis |
| ellos/ellas/ustedes | hablaron |

**comer**

| persona | forma |
|---|---|
| yo | comí |
| tú | comiste |
| él/ella/usted | comió |
| nosotros | comimos |
| vosotros | comisteis |
| ellos/ellas/ustedes | comieron |

**vivir**

| persona | forma |
|---|---|
| yo | viví |
| tú | viviste |
| él/ella/usted | vivió |
| nosotros | vivimos |
| vosotros | vivisteis |
| ellos/ellas/ustedes | vivieron |

## Errores comunes

- Olvidar el acento en yo/él (*hable* ✗ → *hablé* ✓, *comio* ✗ → *comió* ✓).
  El acento aquí no es decorativo: sin él, *hable* es subjuntivo presente,
  no pretérito.
